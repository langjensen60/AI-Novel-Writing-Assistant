## 2024-05-18 - App Logo Navigation Link
**Learning:** Found that the main application logo and title in the navigation bar were static elements, lacking the standard expected behavior of navigating back to the home page when clicked. This is a crucial interaction pattern for web applications.
**Action:** Always verify if primary branding elements in headers/navbars act as functional navigation links to the dashboard/home, and ensure they have appropriate focus and hover states for accessibility.
